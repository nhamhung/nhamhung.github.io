# NUS Career Talk - Intent Analysis

## Classification

New user-facing feature in an existing React/TypeScript/Vite portfolio. Multiple components will be involved: route entry, Vietnamese teaching content, presentation controls, field visualisations and styles. Complexity is moderate; standard requirements depth is appropriate.

## Outcomes

Students can explain the overlap and differences between Computer Science and Computer Engineering, connect NUS CS focus areas to real applications and possible careers, and identify an approachable first project. The presenter can guide an engaging Vietnamese talk.

## Known scope

The user requests the CS/CE distinction, NUS specialisation introduction, application and career visuals for each specialisation, and an exciting ending. Undergraduate terminology should follow the official NUS focus-area source; separate degrees must remain distinct. Do not infer personal anecdotes or endorsements.

## Completeness assessment

- Functional: presentation format, interaction depth and area coverage await answers.
- Non-functional: propose responsive, projection-readable, keyboard-operable visuals with reduced-motion alternatives and local demonstrations.
- User scenarios: live presenter and independent student; relative emphasis awaits format choice.
- Business context: high-school career guidance; talk duration awaits answer.
- Technical: existing static hosting and hash routing; discoverability awaits answer.
- Quality: content accuracy requires official NUS references, illustrative career mappings and portfolio regression checks.
