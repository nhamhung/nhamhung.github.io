# Component Inventory

- Application packages: one React/Vite portfolio.
- Deployment configuration: one GitHub Actions workflow for Pages.
- Templates: exactly two, Engineering and Business.
- App orchestration: App and PortfolioApp.
- Shared UI: navigation, style selector, actions, cards, section shells, provider and colour-mode helpers.
- Content components: Home, About, Education, Experience, Awards, Projects, Gallery, Journal, Skills and Contact; Business supplies its own presentation components and journal page.
- Content/model modules: typed data, portfolio types, local Markdown and bundled media.
- Browser helpers: layout, journal, storage, scroll, media, contact and animation.
- Verification: Vitest/jsdom, Testing Library, TypeScript and ESLint configuration.

There are no server, database or infrastructure service packages. File and test counts are intentionally not treated as fixed architectural facts.
